# Phase 4：實機驗收（GPU＋瀏覽器，2026-11-09）

環境：ComfyUI 0.36.0 @ 127.0.0.1:8190（RTX 5080）、真後端 uvicorn @ 8030（暫用 storage，不是正式 `storage/app.db`）、
前端正式版（`BACKEND_URL=http://127.0.0.1:8030 npm run build` → `node .next/standalone/server.js` @ 3030）。
用 Playwright（chromium、`--disable-gpu`）照使用者操作走一遍；截圖在 `processed/`（不進版控），時間軸在 `timeline.txt`。

## 流程與時間（從開首頁起算）

| 步驟 | 時間 |
|---|---|
| 建 A4 印刷廠繪本（對話框） | 0.4 s |

以一天 8 小時、每頁平均挑圖＋修線 5–10 分鐘估算，20 頁的目標在介面面是可行的；實際瓶頸會在「候選圖品質」與人工判斷。

## 觀察到的問題（非介面 bug）

1. **生成品質**：選中的第一張候選沒有廚房背景（畫的道具與「in a cozy kitchen」幾乎被忽略），第 4 張才有完整廚房。IP-Adapter 0.55 時角色主導畫面，構圖強度 0.4 對簡單方框的約束偏弱。建議 Phase 5 再調：構圖強度預設、提示詞把場景放前面、或候選數改為可選。
2. **角色細節不一致**：本頁的角色鞋子、襪子與參考圖不同（參考圖紅鞋條紋襪）。這正是人工「角色外型」檢查要抓的；此次實測直接標一致，只為走完流程。
3. **手機版 QA 分頁**：三張圖直排很長（約 2900 px）。電腦為主可以接受；之後可改成手機上用分頁切換三張圖。
