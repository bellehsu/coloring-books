## C：換一張背景 → 復原 → 重做
- 腳本這一步誤判為失敗：腳本用了不存在的 `GET /api/pages/{id}` 取原本的狀態，又在新圖還沒到時就按了復原，不是產品的問題。
- 另外用 API 在真 GPU 上補驗（第 5 頁）：
  - 「AI 再畫一張」26 s 後新圖自動換上並重新合成（bg 10 → 44，合成 26 → 45），can_undo 變成 true。
  - 「復原」2 s 回到原背景與**原本那張合成圖**（bg 10、合成 26）。
  - 「重做」回到新背景與新合成圖（44／45），狀態維持可以印。
- 觀察：如果在新圖還沒到時就按復原，新圖到了之後**不會**蓋掉復原的結果，只記成 `auto_*`；「還原成自動畫的那張」可以換上它。這是合理的行為。
