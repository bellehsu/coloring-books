# 編輯頁「主角位置」快捷鈕 — 設計（小改動）

日期：2026-11-19　狀態：使用者已確認（「可以，開始做」）

## 為什麼
主題包（環遊世界、台灣景點）的地標常被置中的主角擋住（中正紀念堂、孔廟、帆船石）。使用者決定位置不寫進主題包文字，
而是做成網頁上每頁可選的選項；放在編輯頁（書做好後看得到背景再調），不放設定頁。

## 做法（使用者確認）
- 編輯頁合成舞台下方（「水平翻轉」「重設位置」那一排上面）加兩組按鈕：位置【靠左｜置中｜靠右】、大小【小｜中｜大】。
- 按下去 = 一次 `onChange(placement)`，和拖曳一樣自動存＋自動合成（Pillow，不用 GPU）。
- 改位置：只改 cx，大小、高度、翻轉不變。改大小：只改 height，cx 不變，腳（底緣 cy + height/2）留在原處。
- 目前位置符合哪個預設，那顆按鈕 `aria-pressed=true`；拖曳到別處時都不亮。
- 只改前端；後端 Placement 範圍不變。

## 數值（我的選擇，依中正紀念堂那頁的試算圖 position_presets.png）
- 位置 cx：靠左 0.26、置中 0.5、靠右 0.74。
- 大小 height：小 0.42、中 0.6（= 預設）、大 0.78。
- 算出來的值經 `clampPlacement`（範圍內、四捨五入 4 位）；比對「目前符合」用 0.005 的容許誤差。

## 不做
設定頁逐頁選位置、主題包文字寫位置、鍵盤快捷鍵、依背景自動避開地標。

## 考慮過的做法
1. 編輯頁快捷鈕（選這個）：看得到背景再決定、改動最小。
2. 設定頁做書前逐頁選：一鍵做書直接照放，但選的時候看不到背景，容易選錯。
3. 兩者都做：工作量最大，使用者沒選。
