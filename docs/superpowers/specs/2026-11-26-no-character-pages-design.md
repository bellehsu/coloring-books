# 不放主角的頁（只畫背景）— 設計

日期：2026-11-26　狀態：草稿，等使用者確認
接在「恐龍、海洋動物、交通安全」主題包（分支 `packs-dino-ocean-safety-2026-11-25`，未合併）之後。

## 1. 為什麼

使用者：「小朋友就是想塗恐龍」。恐龍主題現在每頁都是「背景（恐龍在一邊、畫小）＋主角」，恐龍只佔半邊。
想要可以選「不放主角」：那頁只畫背景，恐龍放在中間、畫大。

## 2. 使用者的決定（2026-11-26）

| 題目 | 決定 |
|---|---|
| 流程 | 先產生主角（照舊）；③ 故事勾「不放主角」→ 每頁都不放；之後每頁可以個別加回主角 |
| 恐龍要變大 | **程式自動改寫場景文字**（三種做法裡選 3；不是每包多寫一組文字、也不是另做一個主題包） |
| 勾選框位置 | ③ 故事標題旁一個**總開關**＋每頁預覽列一個勾選框（可個別改） |
| 加回主角時背景 | 背景是一整張圖，恐龍移不動 → 取消勾選時跳小選擇：**「重畫背景（恐龍移到旁邊）」預設**，或「保留背景，主角我自己調位置」 |
| 影響其他主題 | 開關預設是「放主角」；沒勾的頁、其他主題、已做好的書都與今天相同 |

我的判斷（已告訴使用者、沒有反對）：
- 書做好之後在一鍵處理頁、進階編輯也有同一個勾選框。
- 主角仍要先設定（使用者說先產生人物）；整本都不放也不跳過主角設定。
- 不放主角的頁只算 1 次生成（背景），做書前的預估照這樣算。
- 華麗相框（肖像模式，位置有 `frame`）的頁勾選框停用，說明「相框頁要放主角」。
- 勾了不放主角，預覽列多一行小字「會畫成：…」顯示改寫後的文字；改寫只在送去生成時做，頁面存的原文不改。

## 3. 目標、非目標、反目標

**目標**
- 每頁一個「放主角」設定（預設放）；不放的頁：不排角色動作，背景用改寫過的文字畫，合成只用背景，照常線稿、補線、匯出。
- 恐龍、海洋動物、動物園這類「畫面右邊／左邊有一隻 X」的頁，不放主角時 X 畫在中間、畫大。
- 做好的頁可以來回切換，舊的圖都留在生成紀錄裡（可復原）。

**非目標**
- 沒寫左右的主題（交通工具、職業…）另外的改寫規則：規則不改字，背景照原文畫（中間可能空，使用者已知道）。
- 讓使用者自訂改寫規則。

**反目標**
- 沒有勾「不放主角」的頁，流程、生成次數、提示詞與今天完全相同。
- 改寫不能改到頁面存的文字（勾回來要能照原文重畫）。
- 不放主角的頁不能卡在「等角色動作」。

## 4. 做法的選擇

1. 每個主題包每頁多寫一句「沒主角」的場景：大小一定對，但每包要多寫、驗收。沒選。
2. 另做「恐龍（只有恐龍）」主題包：不能逐頁選。沒選。
3. **程式自動改寫（採用）**：一條規則套在所有頁；缺點是規則可能改壞句子，所以先用 GPU 試畫驗證（§7）。

## 5. 設計

### 5.1 改寫規則（`no_character_scene(scene)`）

依序：
1. 「畫面右邊」「畫面左邊」→「畫面中間」。
2. 拿掉「小小的」。
3. 用「，」切句；第一個含「畫面中間」的句子後面插入「畫得很大，佔滿大半個畫面」。沒有這種句子就不插。

例：「史前時代的草原，畫面右邊有一隻張大嘴巴的暴龍，背景簡單…」→「史前時代的草原，畫面中間有一隻張大嘴巴的暴龍，畫得很大，佔滿大半個畫面，背景簡單…」。
措辭以 §7 試畫結果為準（可能微調插入的字）。

規則要在後端（送去生成）與前端（預覽「會畫成：」）各有一份：用同一份測試案例 JSON（例如
`frontend/src/lib/noCharacterScene.cases.json`，pytest 也讀它）確保兩邊結果一樣。

### 5.2 資料

- `Page.include_character: bool = True`（migration 0017，server_default true）。`PATCH /api/pages/{id}` 接受、`PageOut` 回傳。
- 背景生成的 `prompt` 存實際送出的（改寫後）文字；`user_text` 照舊存頁面原文（生成紀錄能看出差別）。

### 5.3 後端流程

- **背景工作**：`include_character=false` 時用 `no_character_scene(page.scene_prompt)`。構圖變化語（`QWEN_BACKGROUND_VARIATIONS`）
  有「主體在左／右／後面」會和「畫面中間、畫大」打架：不放主角的頁只用「在中間」類的變化語（另一組，至少兩句，讓「再畫一張」仍有變化；
  措辭依 §7）（我的判斷）。
- **做書／產生素材（produce、produce_plan、materials batch）**：不放主角的頁不排角色動作、不算它的次數；也不因缺角色動作而跳過。
- **頁面流程（pipeline）**：不放主角的頁只要有背景就往下走；合成用「只有背景」（產生一筆 composite，內容就是背景；
  沿用 composite／線稿／補線／歷史的路徑）。不設 `review_pose`、不做角色檢查。
- **切換的時機**（我的判斷）：切換要重畫背景時，`include_character` 不立刻改；意圖記在那筆背景生成上（同 take／review 的做法），
  新背景成功換上時才一起改；失敗或取消時頁面維持原狀（不會出現「舊的半邊背景單獨合成」）。保留背景的切換（0 次或只排角色動作）立即改。
- **一定換上**（我的判斷）：切換產生的背景在一鍵處理頁和進階編輯都一定換上（take），兩處都先存復原快照。
- **上傳的背景**（我的判斷）：關掉主角只把上傳的背景單獨重新合成（0 次，沒有「會畫成」小字）；加回主角時小選擇只有「保留背景」
  （不會丟掉使用者上傳的圖）。設定頁選「↑ 上傳背景」的列，勾選框照樣可勾，效果同上。
- **切換（已做好的頁）**：新端點（名稱留給實作者），例如 `POST /api/pages/{id}/character`，body `{include: bool, redraw_background: bool}`，可帶 `?oneclick=true`：
  - 關掉主角：設 false，用改寫文字重畫背景（1 次），好了換上、重新合成。
  - 加回主角＋重畫背景（預設）：設 true，用原文重畫背景；沒有可用的角色動作就再排一個（共 1–2 次）。
  - 加回主角＋保留背景：設 true，背景不動；有可用的角色動作就直接合成（0 次），沒有就排一個（1 次）。主角位置之後使用者自己在構圖調。
  - oneclick：先存復原快照（同「AI 再畫一張」），好了一定換上。次數不夠回 429（同現在的訊息）。
  - 頁面位置有 `frame`（肖像模式）→ 409「相框頁要放主角」。
- **PATCH 改 `include_character`**（設定頁、還沒產生圖的頁）：只改欄位、標 `redraw_background`（如果已有背景）讓「繼續做」重畫；不立即排工作。
- 不放主角的頁「頁面狀態」：有背景＋合成＋線稿就可以印。

### 5.4 前端

- **③ 故事**（`StorySection`）：標題列旁加「☐ 不放主角」總開關；每頁預覽列加勾選框。總開關勾／取消會改全部頁；
  個別頁改過後總開關顯示「部分」（indeterminate）。勾了的頁下方一行小字「會畫成：<改寫後文字>」。
  按「開始做這本書」時把每頁的設定一起存（新頁建立時、既有頁 PATCH）。相框頁（主題包 placements 有 frame）勾選框停用＋說明。
- **一鍵處理頁**（`/books/{id}/page/{pid}`）：角色動作那一列上方加勾選框「放主角」。不放時隱藏角色動作列（或顯示「這頁不放主角」）。
  取消勾選（加回主角）跳小選擇：「重畫背景（恐龍移到旁邊）」（預設）／「保留背景，主角我自己調位置」，並寫出各要幾次。
- **進階編輯 ① 構圖**（`frontend/src/features/editor/ComposeWorkspace.tsx`）：右欄同一個勾選框與小選擇；不放主角時舞台只顯示背景、隱藏角色位置的控制。
- 整本總覽、匯出：照舊（不放主角的頁就是一張圖）。

## 6. 驗收

- 單元測試：改寫規則（共用案例：暴龍、迅猛龍「小小的」、翼龍天空、沒有左右的句子不變、相框文字不變）；migration；
  PATCH／PageOut；背景工作用改寫文字、prompt 記錄；produce 不排角色動作、次數；pipeline 只有背景時合成、可以印；
  切換端點四種情況與 409／429；相框頁不能關；沒勾的頁流程不變。
- 前端：總開關／個別勾選／indeterminate、「會畫成」小字、開始做時存設定、一鍵處理頁與構圖的勾選框和小選擇、相框頁停用。
- GPU 驗收（先問 roboskin-71）：用雪花小女孩做一本恐龍書，全部不放主角，縮圖總表；再在一鍵處理頁把一頁加回主角（兩種選擇各一次），截圖給使用者。

## 7. 試畫（寫程式前）

用 scratch 後端（真正的背景提示詞路徑）畫：暴龍、迅猛龍、翼龍、蛇頸龍套用規則各 2 張（變化語隨機，記下每張用了哪句），看恐龍是否在中間、變大；結果決定 §5.1 的措辭。
同一輪也試畫雙冠龍、禽龍各 3 張，換掉畫不出來的厚頭龍（主題包文字的修正，在主題包分支上）。

切換端點的名稱與回應格式、「只有背景」的 composite 怎麼存（直接複製背景或沿用 compose 函式）、總開關在沒有頁時的狀態、
e2e 是否擴充假後端。分支：主題包分支先提交改好的文字（翼龍、棘龍、厚頭龍暫定，已提交 a29a0ba），再從 `packs-dino-ocean-safety-2026-11-25` 開新分支 `no-character-pages-2026-11-26`，兩者驗收後一起合併。

### 7.1 試畫結果（2026-11-26，`experiments/results/packs_dino_ocean_safety_20261125/sheet_nochar_spike.png`）

- 改寫規則 §5.1 原樣可用：暴龍、迅猛龍、翼龍、蛇頸龍 8/8 恐龍明顯變大、靠中間（有主角版本只佔約 1/4 寬）。
  其中 4 張抽到「主體在左／右／後面」的變化語，仍然畫大，但有 1 張（暴龍、左邊）主體被切掉一部分 → 照 §5.3 改用「在中間」類變化語。
- 換厚頭龍：禽龍 3/3（兩腳站、尖拇指）、雙冠龍 0/3（頭冠畫成兔耳或扇子）→ 恐龍包改成禽龍（主題包分支 1d177ae）。
